- [can-utils](can-utils.md) — Linux-CAN SocketCAN userspace utilities including cansniffer, candump, cansend, canplayer, and cangen for CAN bus analysis.
- [CANalyse](canalyse.md) — Vehicle network analysis tool with SQL-like queries on CAN data, smart signal scanning, and Telegram bot integration.
- [CANalyzat0r](canalyzat0r.md) — Security analysis toolkit for proprietary car protocols with graphical sniffing, fuzzing, packet comparison, background-noise filtering, and UDS fuzzing.
- [CANarchy](canarchy.md) — Stream-first CAN and J1939 toolkit that emits structured JSONL for automation, with live capture, DBC/ARXML/KCD decoding, J1939 PGN/SPN and DM1 fault…
- [CanCat](cancat.md) — Firmware for Arduino CAN shields and Macchina M2 boards paired with a Python client for sniffing and injecting CAN traffic, running UDS and CCP sessions…
- [CANdevStudio](candevstudio.md) — Flow-based graphical CAN simulation environment that wires senders, receivers, DBC decoders, and signal viewers together to stand in for missing ECUs on a…
- [CANExplorer](canexplorer.md) — Cross-platform CAN, CAN FD, and LIN analysis GUI with reverse-engineering tools, UDS discovery and fuzzing, DoIP and SOME/IP support, and SecOC decoding.
- [CANflict](canflict.md) — C library that manipulates the CAN bus at the data link layer from an unmodified microcontroller, abusing pin conflicts between peripherals to craft…
- [CANgaroo](cangaroo.md) — Open-source CAN bus analyzer for Linux and Windows with DBC and LDF decoding, CAN FD, Python scripting, SocketCAN, PEAK, Kvaser, Vector, and candlelight…
- [CanLab](canlab.md) — PyQt6 desktop application for offline CAN capture reverse engineering, combining automated counter and checksum detection with entropy-based signal boundary…
- [canmatrix](canmatrix.md) — Python package to read and write CAN database formats, converting between DBC, ARXML, KCD, SYM, LDF, ODX, and more.
- [cannelloni](cannelloni.md) — Tunnels SocketCAN interfaces over UDP, TCP, or SCTP, bridging a vehicle bus to a remote analysis machine and letting bench setups share one physical CAN…
- [CANter](canter.md) — Intrusion detection system for CAN and CAN-FD that detects drop-and-spoof attacks using frequency analysis of frame intervals.
- [cantools](cantools.md) — Python library for CAN bus diagnostics, DBC parsing, and message decoding/encoding.
- [CANToolz](cantoolz.md) — Black-box CAN network analysis framework also known as YACHT with modular architecture for fuzzing and ECU discovery.
- [canTot](cantot.md) — Metasploit-style CAN bus exploitation framework built on sploitkit, packaging published vehicle-specific CAN attacks as selectable modules.
- [CaringCaribou](caringcaribou.md) — Python automotive security exploration tool designed as the nmap of CAN bus with fuzzing, ECU discovery, and attack modules.
- [Carpunk](carpunk.md) — CAN injection toolkit and successor to CANghost, automating interface setup, sniffing, replay, and injection attacks.
- [ICSim](icsim.md) — Instrument Cluster Simulator for safe CAN bus security testing with virtual dashboard controls.
- [Kayak](kayak.md) — Java-based CAN bus analysis tool with bus monitoring and DBC/KCD file loading support.
- [Lindwurm](lindwurm.md) — Open-source CAN bus tracing and fuzzing tool designed for penetration testing with Burp Suite-inspired workflow.
- [OBDium](obdium.md) — Rust-based OBD-II diagnostic tool with modern Tauri GUI supporting live data, DTC analysis, and offline VIN decoding.
- [opendbc](opendbc.md) — Python API for your car, bundling community-maintained DBC files with CAN parsing and car interface libraries for reading vehicle state and actuating controls.
- [pretty_j1939](pretty-j1939.md) — NMFTA's Python library and CLI that decodes J1939 traffic from candump logs using the SAE J1939 Digital Annex, with transport protocol reassembly…
- [python-can](python-can.md) — Python library providing a common interface over many CAN hardware backends with CAN FD support and logging to ASC, BLF, MF4, TRC, CSV, and SQLite.
- [python-can-isotp](python-can-isotp.md) — ISO-TP (ISO 15765) transport for Python on top of python-can or Linux SocketCAN, the segmentation layer that UDS and OBD-II diagnostics run over.
- [SavvyCAN](savvycan.md) — Cross-platform Qt-based CAN bus reverse engineering and capture tool with DBC file loading, UDS scanning, and fuzzing support.
