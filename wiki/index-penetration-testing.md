# Penetration Testing

- [AutoFuze](autofuze.md) — Python toolkit for fuzzing and penetration testing ECUs over UDS, XCP, SOME/IP, and OBD, across CAN, DoIP, USB, and SPI transports.
- [automotive-security-research](automotive-security-research.md) — Published reverse engineering results for two production vehicles including CAN matrices, extracted ECU security access keys, and UDS scanning…
- [CANHack](canhack.md) — Ken Tindell's proof-of-concept toolkit of low-level CAN protocol attacks such as Janus frames, bit-banged from a Raspberry Pi Pico on the CANPico board…
- [Car Toolkit](car-toolkit.md) — Python-based toolkit for automotive penetration testing with CAN suite, CARAL, and virtual test bench setup.
- [DongleScope](donglescope.md) — Automated tool for detecting vulnerabilities in wireless OBD-II dongles based on USENIX Security 2020 research.
- [NullSec CarFuzz](nullsec-carfuzz.md) — Rust fuzzer for CAN, UDS, OBD-II, and DoIP with grammar-aware test generation and coverage tracking.
- [PiCCANTE](piccante.md) — Dirt-cheap CAN bus exploration tool built on Raspberry Pi Pico as an open-source hardware/software solution.
- [pwnobd](pwnobd.md) — Offensive cybersecurity toolkit for vulnerability analysis of OBD-II devices presented at Black Hat Europe 2024.
- [SecOC Key Extractor](secoc-key-extractor.md) — Scripts to extract SecOC (Secure On-Board Communication) keys from Toyota vehicles using comma.ai panda hardware.
- [tesla-opener](tesla-opener.md) — Open-source tool to open Tesla charging port using HackRF and WebUSB with ASK/OOK RF transmission.
- [TruckDevil](truckdevil.md) — Framework for assessing heavy-vehicle ECUs that communicate over J1939, with ECU discovery, message reading and sending, and a J1939 fuzzer, running on a…
