Comprehensive CAN bus security resources.

iDoka's companion list to the CAN ID database above: CAN bus tools, hardware, and resources collected for security researchers, reverse engineers, and automotive electronics enthusiasts — the shopping-and-reading list for equipping a CAN bench, from interfaces and analysers to protocol references.

It is one of the most-used CAN references on GitHub (3,541 stars), and between this list (tools) and its sibling (decoded IDs) most CAN questions a newcomer brings to the KB are answered in one of the two. Same caveat as any curated list: inclusion is not endorsement, and tool quality varies — check a project's own repository before relying on it.
